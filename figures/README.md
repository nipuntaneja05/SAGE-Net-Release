# Figures

`cvpr-paper/figures/` contains the figures referenced by the manuscript. The earlier unlinked root-level PNG/SVG analysis outputs were removed during release cleanup. Training diagnostics are written beside run JSON files under `results/generated/`; the paper summary renderer writes summary SVGs to `figures/generated/`.

The manuscript reliability analysis is a seed-42 subset summary. It does not establish per-example gate behavior or a general reliability guarantee.
